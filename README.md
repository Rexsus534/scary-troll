# SCARY TROLL — düzeltilmiş sürüm

## Kontroller
- W: ileri, S: geri, A/D: sağ-sol
- Mouse: etrafa bak
- Shift: koş
- E: etkileşim
- F: fener
- Mobil: sol joystick + sağdaki butonlar

## Canavar ve jumpscare
Oyun, Grab3D üzerindeki ücretsiz CC0 Horror Monster modelinin hafif GLB sürümünü yüklemeyi dener. Model indirimi: https://grab3d.com/models/creatures/horror-monster/ . Model yüklenemezse oyundaki yedek canavar kullanılır. Modelin kendisi statik pozdadır; oyun içinde takip hareketi, yaklaşma ve kameraya doğru 3D jumpscare animasyonu kodla uygulanır.

Modeli ilk kez yüklemek için internet bağlantısı gerekir. Three.js de jsDelivr CDN üzerinden yüklenir.
